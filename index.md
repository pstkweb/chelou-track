# Chelou Track

Lecteur desktop de méthodes de guitare : vidéos et exercices stockés sur votre
propre compte cloud (pCloud, Dropbox, Google Drive), avec une vue synchronisant
un backing track audio et une tablature GuitarPro. Streaming direct, sans
téléchargement ni copie sur un serveur tiers.
